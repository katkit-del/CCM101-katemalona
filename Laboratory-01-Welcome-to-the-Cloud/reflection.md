# Reflection

## What did you learn from this activity?
I learned how to use basic Linux commands like creating a user, checking system
information, and making folders and files in the terminal. I also learned how to
use Git and GitHub to save and upload my work online.

## What challenges did you encounter, and how did you solve them?
I had a problem when pushing my files to GitHub because I forgot to change the
placeholder username in the command, which caused an error. I fixed it by checking
my actual GitHub username and using the correct link, and after that the push worked.

## How does this relate to real-world cloud engineering work?
This activity showed me that cloud engineers need to be comfortable using the
terminal and keeping their work organized and saved online. It also taught me that
small mistakes, like a wrong command, are normal and just need to be fixed carefully.
