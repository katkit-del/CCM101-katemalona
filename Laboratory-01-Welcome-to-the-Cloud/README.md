# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory is the onboarding mission for a Junior Cloud Infrastructure
Engineer Trainee at CloudNova Technologies. It covers working inside a Linux
environment, documenting work with Markdown, and maintaining a
version-controlled portfolio on GitHub.

## Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux operating system
- Gather basic system information
- Organize files and directories using Linux commands
- Create and maintain a professional GitHub repository
- Document technical work using Markdown

## Activities Performed
- Launched an Ubuntu 24.04 environment on KillerCoda
- Created user `kmalona` with sudo privileges and logged in
- Recorded username, working directory, and hostname
- Gathered system information (distro, kernel, CPU, memory, disk space)
- Built a folder structure and Markdown notes
- Created and pushed a public GitHub portfolio repository
- Documented the mission and captured evidence via screenshots

## Linux Commands Used
| Command | Purpose |
|---|---|
| `sudo adduser` | Create a new user |
| `sudo usermod -aG sudo` | Grant sudo privileges |
| `su -` | Switch user |
| `whoami` / `pwd` / `hostname` | Identify user, location, machine |
| `lsb_release -a` | Show distro info |
| `uname -r` | Show kernel version |
| `lscpu` | Show CPU info |
| `free -h` | Show memory usage |
| `df -h` | Show disk space |
| `mkdir -p` | Create nested folders |
| `cat` / `nano` | Create and edit files |
| `ls -R` | View directory tree |
| `git init/add/commit/push` | Version control to GitHub |

## Skills Learned
- Basic Linux navigation and system administration
- User and permission management
- Markdown documentation
- Git and GitHub workflow for a version-controlled portfolio
