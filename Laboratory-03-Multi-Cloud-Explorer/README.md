# Laboratory 03 – Multi-Cloud Explorer

## Linux-to-Cloud Migration

**System findings from KillerCoda:**
- Distribution: Ubuntu 24.04.4 LTS
- Kernel Version: 6.8.0-136-generic
- CPU: Intel Xeon E312xx
- Total Memory: 1.9Gi
- Available Disk Space: 13G

**Which cloud services could host this server?**
A Linux server like this maps to a virtual machine instance on each
platform: Amazon EC2 on AWS, Azure Virtual Machines on Microsoft Azure,
and Compute Engine on Google Cloud Platform. All three let you choose a
VM size, attach persistent disk storage, and run Ubuntu as the guest OS.
