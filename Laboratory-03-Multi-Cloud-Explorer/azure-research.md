# Microsoft Azure Research

## Brief Overview
Azure is Microsoft's cloud computing platform. It works a lot like AWS, but
it's built to connect easily with other Microsoft products like Windows
Server, Microsoft 365, and Active Directory.

## Global Infrastructure
Azure has one of the largest global footprints, with numbers commonly cited
around 60-70+ regions.

## Cloud Management Console
It's called the Azure Portal — that's where you manage your resources.

## Four (4) Core Services
1. Azure Virtual Machines – for renting virtual servers
2. Azure Blob Storage – for storing files and data
3. Microsoft Entra ID (formerly Azure Active Directory) – for managing
   user identity and access
4. Azure Virtual Network – for setting up private networks

## Three (3) Advantages
1. It connects smoothly with Microsoft tools businesses already use, like
   Windows Server and Office 365.
2. It's a strong option for companies that need hybrid setups (part
   on-site, part cloud).
3. It has strong support for enterprise security and compliance needs.

## Typical Enterprise Use Cases
Companies that already run on Microsoft software use Azure to move parts of
their systems to the cloud, manage user accounts and permissions across the
organization, and run business apps that work with Office 365.
