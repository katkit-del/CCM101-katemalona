# Amazon Web Services (AWS) Research

## Brief Overview
AWS is a cloud computing platform run by Amazon. It lets people and businesses
rent servers, storage, and other computing tools online instead of buying
their own hardware. It's the biggest and oldest cloud provider out of the
three.

## Global Infrastructure
AWS has around 39 regions and over 120 availability zones spread across
the world.

## Cloud Management Console
It's called the AWS Management Console — that's what you log into to create
and manage things like servers or storage.

## Four (4) Core Services
1. EC2 (Elastic Compute Cloud) – for renting virtual servers
2. S3 (Simple Storage Service) – for storing files and data
3. IAM (Identity and Access Management) – for managing user access
4. VPC (Virtual Private Cloud) – for setting up private networks

## Three (3) Advantages
1. It has the widest range of services of any cloud provider.
2. It has the most regions and data centers, so it's easy to host apps
   close to users anywhere in the world.
3. It has a huge community and lots of documentation, so it's easier to
   find help when something goes wrong.

## Typical Enterprise Use Cases
Companies use AWS for hosting websites and apps, storing large amounts of
data, running AI/machine learning workloads, and building scalable
e-commerce platforms that need to handle a lot of traffic.
